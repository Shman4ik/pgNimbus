# Where this skill came from

`SKILL.md` is vendored verbatim from <https://github.com/blader/humanizer>
(version 2.9.1, MIT licensed; `LICENSE` is the upstream copy). It is not
maintained here.

To update it, re-copy `SKILL.md` and `LICENSE` from upstream rather than editing
them in place, so local changes never silently diverge from the source.

The skill codifies Wikipedia's "Signs of AI writing" guide as an editing pass.
Use it on prose that ships to users: the README, the pages under `docs/`, release
notes, and the project website copy.

## One standing deviation

The README's section headings keep their emoji (`## Installation` is written
`## 📦 Installation`). Section 18 of the skill says to cut emoji, but its own
Voice Calibration rule says an established author voice outranks its style
rules, and those headings predate the skill and are part of how the project
presents itself on GitHub. Everything else in the skill applies to the README as
written.
