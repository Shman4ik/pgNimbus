A fast, open-source PostgreSQL GUI client

Why pgNimbus

The gap in the Postgres client market: truly fast + open source + modern UI. pgAdmin and DBeaver are heavy; TablePlus is closed and paid; HeidiSQL is dated and MySQL-first.

Instantly fast

A NativeAOT binary, not an Electron shell: on screen in about 0.2 s. Startup, memory, and query-engine numbers are measured on every release.

PostgreSQL-first

Deep pg_catalog introspection, graphical EXPLAIN, FK-aware JOIN completion, roles and permissions, LISTEN/NOTIFY, server activity. Never the lowest-common-denominator dialect.

Keyboard-first

A Ctrl+K command palette that fuzzy-jumps to any table, query, or action; run, cancel, and navigate without touching the mouse. F1 shows every binding.

Private & open

Zero telemetry: no analytics, no automatic crash reports, no update pings. Passwords are encrypted by the OS (DPAPI, Keychain, Secret Service). MIT-licensed, so you can verify it, not trust it. Privacy details.

Everything you need, nothing you don't

A minimalist shell over a serious engine. Secondary actions live in the palette, not on a toolbar.

  • Streaming, cancellable results. The first screenful renders before the full result set arrives, in a virtualized grid.
  • Safe mode. Stage grid edits, inserts and deletes, review the exact SQL, and commit them as one transaction. If someone else changed a row in the meantime, you see before, now and yours side by side.
  • SQL completion that reads SQL like the server. Only what can legally come next at the caret: tables, scoped columns, aliases, CTE columns, functions, DDL. A join and its ON condition in one accept.
  • Browse without writing SQL. Paged, sortable browsing pushed down to Postgres, filter chips per column, a row details card, and a hand-typed WHERE comes back as chips.
  • Follow foreign keys from the grid. Jump to the referenced row, or list every row that references this one.
  • Roles and permissions. Ask whether a role can do something and see why: a direct grant, a group, PUBLIC, ownership. Grants come out as a script you review, never applied behind your back.
  • Server insight. Live activity with a who-blocks-whom lock tree, a database overview, a slow-query shortlist from pg_stat_statements, and a LISTEN/NOTIFY monitor.
  • Read-only connections. Mark a profile read-only and the server itself refuses writes.
  • Transaction control. Explicit Begin, Commit and Rollback on one held connection, with rollback on failure.
  • Multi-tab editor. SQL formatting, find and replace, run history, saved queries, whole-script execution, and closed tabs come back with Ctrl+Shift+T.
  • Cell inspector. Press Space on any cell to read a long text or jsonb value, pretty-printed or as a tree.
  • Import and export. Type-inferred CSV and JSON imports through COPY. Export writes every row, not just the page on screen. Copy results as CSV, JSON, Markdown or INSERTs.
  • Connection manager. Paste a URI, a JDBC URL, libpq keywords or a whole psql command line and the form fills itself. Per-connection accent colors, SSH tunnels with agent auth and checked host keys, TLS verification, and passwords only in the OS credential store.

Download

Windows is the primary target; macOS and Linux builds ship as early betas.

Windows

The Microsoft Store build is signed by the Store: no SmartScreen warnings, and updates arrive on their own.

Microsoft Store

winget install pgNimbus --source msstore

Prefer a plain installer? Grab the per-user MSI from Releases (unsigned, so SmartScreen warns once).

macOS (early beta)

Apple Silicon .dmg (macOS 12 or later) from GitHub Releases. Drag pgNimbus to Applications, then right-click it and choose Open the first time:

Right-click → Open → Open

Download .dmg

The build is ad-hoc signed, not notarized, so macOS asks once. Until notarized builds ship, an update can leave saved passwords unreadable, and deleting the old pgNimbus items in Keychain Access fixes it. Details in the installation guide.

Linux (early beta)

x64 and arm64 from GitHub Releases. The AppImage runs on any distro. Make it executable and launch it:

chmod +x pgNimbus-*.AppImage

Download AppImage

Debian/Ubuntu .deb and a plain .tar.gz are on the same Releases page.
